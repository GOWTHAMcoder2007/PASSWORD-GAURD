# Password Guard 🔐

## Project Description

**Password Guard** is a cybersecurity project designed to help users evaluate and improve the security of their passwords. The application analyzes a password locally and provides a **strength score out of 100**, along with a detailed checklist showing which security requirements are satisfied and which need improvement.

The tool checks important password security factors such as **password length, uppercase letters, lowercase letters, numbers, special characters, repeated characters, common passwords, and obvious sequences**.

Password Guard also includes a **Strong Password Generator**, allowing users to select the desired password length and character types, including uppercase letters, lowercase letters, numbers, and special characters.

### 🔐 Key Features

* **Password Strength Analyzer**

  * Evaluates the entered password.
  * Generates a security score from **0–100**.
  * Provides real-time password analysis.

* **Security Requirement Checklist**

  * Checks for minimum password length.
  * Detects uppercase and lowercase characters.
  * Checks for numbers and special characters.
  * Detects common passwords.
  * Identifies obvious sequences.
  * Detects excessive character repetition.

* **Strong Password Generator**

  * Generates random strong passwords.
  * Customizable password length.
  * Supports uppercase letters.
  * Supports lowercase letters.
  * Supports numbers.
  * Supports special characters.

* **Privacy Focused**

  * Password analysis is performed locally.
  * Passwords are not intended to be stored or transmitted.
  * Designed with privacy and security in mind.

### 🎯 Objective

The main objective of Password Guard is to create a simple and user-friendly cybersecurity tool that helps users understand **why a password is weak or strong** and encourages them to use more secure passwords.
